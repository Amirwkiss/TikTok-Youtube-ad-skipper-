# Обработка данных

Расширение работает на страницах YouTube и TikTok.

- Для поиска размеченных отрезков YouTube отправляет идентификатор видео в SponsorBlock API. Настраиваемые данные аккаунта туда не отправляются.
- При распознавании речи получает звук текущего видео или вкладки TikTok либо YouTube. Локальный режим обрабатывает звук в браузере. Облачный режим включается только после отдельного согласия; Chrome может передавать звук своему сервису распознавания.
- Расширение не записывает звук и не сохраняет расшифровки. Последний распознанный фрагмент может временно отображаться в подсказке значка расширения для диагностики.
- В локальном хранилище Chrome сохраняется только выбор пользователя об облачном распознавании. Его можно отозвать в параметрах расширения.
- Собственной аналитики, рекламы и удалённого кода в расширении нет.

Облачный режим и SponsorBlock зависят от доступности внешних сервисов и их правил обработки данных.
