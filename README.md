# Пропуск рекламы в видео

Проект создан с помощью ChatGPT. Это ранняя версия расширения: сейчас мы в первую очередь проверяем пропуск рекламы Musor Drop в TikTok. В наших проверках этот сценарий работает хорошо. Поддержку других рекламных вставок будем расширять и улучшать по мере тестирования.

Расширение ищет рекламные признаки в тексте и речи ролика и при обнаружении пытается перемотать видео на 4 секунды. Точное окончание рекламы оно пока не определяет, поэтому длинная вставка может пропуститься лишь частично. Список названий ниже означает, что расширение умеет их искать, но не обещает одинаковую точность для каждого бренда и ролика.

Расширение для Chrome и Edge. На YouTube оно автоматически пропускает размеченные рекламные отрезки через [SponsorBlock API](https://wiki.sponsor.ajay.app/w/API_Docs). Если в субтитрах YouTube или TikTok появляется название из списка ниже, оно перематывает на 4 секунды. На TikTok оно также проверяет рекламную метку, описание и произнесённые слова. Отмечать рекламу в отдельных роликах не нужно.

Распознаются Upgrader, Musor Drop, Float Up, GGDrop, ForceDrop, Skin.Club, Hellcase и Key-Drop, включая некоторые русские варианты произношения. Дополнительные площадки выбраны по их [сотрудничеству с авторами](https://hellcase.com/ru/faq), [рекламным публикациям](https://community.skin.club/en/news/stage-2-austin-major-pickem-predictions-by-shox) и [партнёрским программам](https://help.key-drop.com/cs/article/i-am-a-content-creator-and-i-want-to-cooperate-with-you). Совпадение названия само по себе не доказывает, что фрагмент является рекламой; возможны ложные пропуски.

## Установка

1. Откройте [страницу последнего релиза](https://github.com/Amirwkiss/TikTok-Youtube-ad-skipper-/releases/latest) и скачайте **`ad-skipper-0.6.0.zip`** из раздела **Assets**. Кнопка **Code → Download ZIP** скачивает исходный код, а не готовый архив релиза.
2. Найдите скачанный ZIP в «Загрузках» и распакуйте его в постоянную отдельную папку, например `Документы\ad-skipper`. Не удаляйте и не переносите эту папку после установки. Внутри должны быть `manifest.json`, `background.js` и остальные файлы расширения. Если после распаковки получилась вложенная папка, выбирайте ту, где лежит `manifest.json`.
3. В Chrome введите в адресную строку `chrome://extensions`. В Edge откройте `edge://extensions`.
4. Включите **Режим разработчика** переключателем в правом верхнем углу страницы. В Edge также может потребоваться разрешить установку расширений из других источников.
5. Нажмите **Загрузить распакованное расширение** и выберите папку из шага 2. В списке появится **«Пропуск рекламы в видео»**, версия **0.6.0**. Убедитесь, что переключатель расширения включён.
6. Откройте или обновите вкладку TikTok. Для поиска рекламы по видимому тексту и субтитрам больше ничего настраивать не нужно. Чтобы расширение пыталось распознавать произнесённые названия, откройте **Сведения → Параметры расширения** и разрешите облачное распознавание. Браузер может передавать звук сервису распознавания Chrome/Google; подробности приведены ниже и в [политике конфиденциальности](PRIVACY.md).
7. Если реклама звучит только в аудио, а автоматический захват видео недоступен, нажмите значок расширения на вкладке TikTok. Это включает захват звука вкладки; повторное нажатие выключает его. Для этого действия Chrome требует нажатия пользователя.

Для обновления установленной версии распакуйте новый архив в ту же папку с заменой файлов, затем нажмите **Обновить** на странице расширений и обновите вкладку TikTok. Не выбирайте ZIP непосредственно в окне загрузки расширения: Chrome и Edge принимают распакованную папку.

## Распознавание голоса в TikTok

После согласия на облачное распознавание расширение пытается автоматически захватить звук текущего видео. Если сайт или браузер не отдаёт аудиодорожку через видеоэлемент, нажмите значок расширения во вкладке TikTok: он включает захват звука всей вкладки. [Для этого Chrome требует действия пользователя](https://developer.chrome.com/docs/extensions/reference/api/tabCapture). Повторное нажатие выключает захват вкладки. При новом открытии вкладки может потребоваться нажать значок снова.

Облачное распознавание включается только после выбора «Разрешить облачное распознавание» в окне расширения; звук может передаваться сервису Chrome/Google. Локальный режим используется, если в Chrome доступен русский языковой пакет. При быстром переключении роликов поздний результат распознавания от предыдущего видео игнорируется.

При захвате всей вкладки значок показывает этап обработки: `CLD` — облачное распознавание запущено, `AUD` — звук поступает, `TXT` — Chrome вернул текст, `SKIP` — переход выполнен, `OLD` — результат пришёл после смены видео, `NO` — переход не удался. Наведите курсор на значок, чтобы увидеть подробность. При автоматическом захвате видео значок может не меняться.

Разрешение на облачное распознавание можно отозвать в настройках расширения на странице `chrome://extensions` → «Сведения» → «Параметры расширения» → «Только текст и субтитры». Это также остановит текущий захват звука.

Если появилась надпись `ERR`, расширение покажет причину ошибки прямо в TikTok. Причину также можно увидеть, наведя мышь на значок расширения. Облачное распознавание тоже может быть недоступно из-за сети или политики браузера. Поиск по тексту и субтитрам продолжит работать.

## Как проверить

1. Откройте видео YouTube, где уже отмечен спонсорский отрезок в SponsorBlock. При достижении начала отрезка видео должно перейти к его концу без нажатий.
2. Для проверки нового ролика без отметки включите субтитры YouTube. Когда в них появится название бренда, видео должно перейти примерно на 4 секунды вперёд.
3. На TikTok откройте ролик с рекламной меткой или названием бренда в субтитрах: он должен перемотаться на 4 секунды.
4. Откройте ролик, где название только произносят. Если автоматическое распознавание недоступно, включите захват всей вкладки значком расширения. Проверьте, что после прокрутки ленты поздний ответ от старого ролика не перематывает новый.

Автоматический тест: `node test.mjs`. Он проверяет определение бренда, границу видео, пропуск известного отрезка YouTube, переход на 4 секунды и передачу распознанной фразы из звука вкладки. Тест не заменяет проверку на живых страницах.

## Ограничения

- SponsorBlock знает только отрезки, отмеченные сообществом; название рекламодателя в ответе API не указывается. Поэтому YouTube пропускает все известные спонсорские вставки, а не только перечисленные бренды.
- Для локального распознавания речи TikTok Chrome использует русский языковой пакет. Если его можно скачать, браузер может загрузить его при первом запуске; другое расширение не нужно. Облачный режим требует явного разрешения и может передавать звук вкладки сервису Chrome/Google.
- Переход на 4 секунды не гарантирует попадание точно в конец рекламы. Распознавание речи Chrome может запаздывать или ошибаться в коротких названиях. Поздний результат после смены ролика отбрасывается.
- Изменения разметки сайтов могут потребовать обновления расширения.
- На YouTube ID видео отправляется в SponsorBlock для поиска временных меток.
